BitCode - Learn how to code in Arabic

Posted by TarepSH

Bit Code is an online platform for learning to build web and mobile applications. The courses are interactive, in Arabic, and free.

We reached 3,500 registered users in the first four months after launch. Bit Code was backed by Oasis500 in Jordan, and won first place in the Jusoor entrepreneurship competition in 2016.

The problem we set out to solve

Programming jobs were growing fast, but Arabic material for learning to code was thin and far from professional. Anyone who wanted to learn had to work in a second language first.

Who it is for

Young Arabs interested in programming, mostly 15 to 23 years old, in MENA and GCC countries where access to this kind of education is limited.

How it works

You learn by writing code, not by watching videos or answering quizzes. You write it directly on the site and build your app step by step. Finishing a challenge earns points and badges you can share with your friends.

That is also the difference from Coursera, edX and the other MOOC platforms. They cover many subjects; Bit Code does one thing, in Arabic, and makes you type every line yourself.
